# University Subjects & Lectures Archive 📚
## كلية الهندسة المعلوماتية - جامعة دمشق (ITE Damascus University)

مستودع شامل لكافة المقررات الدراسية والمحاضرات الجامعية لجميع السنوات الخمس في كلية الهندسة المعلوماتية بجامعة دمشق، منظمة ومصنفة زمنياً حسب تاريخ كل محاضرة ونوعها (نظري / عملي).

### 📊 إحصائيات المستودع:
* **إجمالي الملفات:** 824 ملف ومحاضرة دراسية (PDF).
* **إجمالي الحجم:** ~1.2 GB.
* **السنوات المشمولة:** كافة السنوات الجامعية (1 إلى 5).
* **المزامنة:** متطابق مع الأرشيف السحابي ومربوط ببوابة علامات ومحاضرات هندسة المعلوماتية.
